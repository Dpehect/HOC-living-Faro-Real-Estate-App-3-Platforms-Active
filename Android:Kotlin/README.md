# HOC Living — Android (Kotlin + Jetpack Compose)

Aligned with the **Web** app (Europe-wide).

## Features (same as Web)
- Homes across Europe · 300k listings · 30 countries
- **Home search** with city/country autocomplete suggestions
- Country picker + city filter on listings (exact city match when name matches, e.g. Reykjavik)
- Live data from Web deployment: `…/data/countries/{Country}.json` and `cities.json`

## Run
Open this folder in Android Studio → Sync → Run (API 26+). Internet required for live catalog.
