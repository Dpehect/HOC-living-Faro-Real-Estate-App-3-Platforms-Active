# HOC Living

Cross-platform real estate product for **München & Bayern**.

**Brand:** HOC Living (no city in the product name)  
**Market:** München and surrounding areas  

## Platforms

| Platform | Stack | Folder |
|----------|--------|--------|
| **Web** | HTML / CSS / JS (static) | `Web/` |
| **Android** | Kotlin + Jetpack Compose | `Android/` |
| **iOS** | Swift + SwiftUI | `iOS/` |

## Features

- Home with hero, stats, featured listings  
- Listings with filters (buy/rent, apartment/house, bedrooms)  
- Property detail with price, specs, description, tour CTA  
- Shared sample catalog (München districts: Schwabing, Maxvorstadt, Bogenhausen, …)

## Quick start

### Web
```bash
cd Web
python3 -m http.server 8080
# open http://localhost:8080
```

### Android
Open `Android/` in Android Studio → Run (API 26+).

### iOS
Open `iOS/HOCLiving.xcodeproj` in Xcode 15+ → Run (iOS 16+).
