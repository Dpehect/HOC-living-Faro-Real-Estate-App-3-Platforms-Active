# HOC Living — Web

React + Vite real estate web app for **München & Bayern**.

**Brand:** HOC Living (no city in the product name)

## Stack

- React 18 + TypeScript
- Vite 5
- Tailwind CSS
- Leaflet (map search)
- Framer Motion
- React Router

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Deploy

Configured for Vercel (`vercel.json`).
