# HOC Living — iOS (SwiftUI)

Aligned with the **Web** app (Europe-wide).

## Features (same as Web)
- Homes across Europe · 300k listings · 30 countries
- **Home search** with city/country autocomplete
- Country picker + city filter (exact city match e.g. Reykjavik)
- Live data from Web: `cities.json` + country JSON files

## Run
Open `HOCLiving.xcodeproj` → Run (iOS 16+). Network required for live catalog.
